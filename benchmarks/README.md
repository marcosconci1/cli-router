# Benchmark sources

Source: [LLM Benchmark v4](https://akitaonrails.com/2026/10/28/llm-benchmark-v4-gemini-4-argon-gpt-sol-6-1-terra-kimi-k3-1-pro-claude-sonnet-5-5/), published 2026-10-28 on akitaonrails.com.

The article reports campaign results for exact model and harness combinations, including total run cost and wall time for each campaign. It also publishes a v4 security vigilance score and a separate engineering breadth index, which carries a 90% coverage label because not every engineering benchmark was available for every model. This repository does not republish the article's tables. The derived per route numbers that `route_benchmark.py` uses for routing are kept inline in that module, with a link back to the source.
